🌦️ Weather App

A simple, responsive Weather App built using HTML, CSS, and JavaScript that allows users to check real-time weather information for different cities. The application fetches weather data from an API and displays important weather details through a user-friendly interface.

🌐 Live Demo

🚀 Try the application here: https://weatherapp-rouge-beta.vercel.app/

✨ Features

- 🔍 Search for weather information by city name.
- 🌡️ Display the current temperature.
- ☁️ Show weather conditions.
- 💧 Display humidity levels.
- 💨 Display wind speed.
- 🌍 Retrieve real-time weather information using an API.
- 📱 Responsive and user-friendly interface.
- ⚡ Dynamically update weather details based on the searched city.
- ❌ Handle invalid city names and API errors.

🛠️ Technologies Used

- HTML5 – Structures the web application.
- CSS3 – Provides styling and responsive layouts.
- JavaScript – Handles application logic and dynamic updates.
- Fetch API – Retrieves weather data asynchronously.
- Weather API – Provides real-time weather information.
- Vercel – Deploys and hosts the application.

⚙️ How It Works

1. Enter a city name in the search field.
2. The application sends a request to the weather API.
3. The API returns weather information in JSON format.
4. JavaScript processes the response.
5. The application displays the corresponding weather details.

🚀 Run Locally

1. Clone this repository:
   
   git clone YOUR_GITHUB_REPOSITORY_URL

3. Configure your weather API key if required.

4. Open "index.html" in your browser or run the application using the Live Server extension.
